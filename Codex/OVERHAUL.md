# Codex portfolio overhaul

Rollback baseline: `a1572bcc1210028de356482d6ecb7de4f9d735d5` (Sol portfolio).

The production site is generated by `npm run build:site` into `_site`. Run `node Codex/preview.cjs` from the repository root for a preview on port 4174. `build.cjs`, `content.cjs`, and `blog-build.cjs` are the source of the new portfolio. The previous HTML/CSS/JavaScript is preserved in the baseline commit rather than duplicated in the working tree. No authoring tools or internal modules are published.

`npm test` builds and audits the generated artifact. `npm run test:artifact` checks an existing artifact. Public repository data is in `repositories.json`, refreshed with `npm run refresh:repositories` and by the daily/manual Pages workflow. A failed API refresh does not replace the snapshot. Blog sources and editor contracts remain unchanged.

Content claims trace to `content.cjs` source references. The two public case studies preserve attribution and avoid unverified performance metrics. Codex stays Ongoing in the comparison portal.

Rollback: create a reviewed revert of the overhaul commit(s) on main and allow the Pages workflow to republish the previous source. Never reset shared history. If restoring the old source, restore the matching package/build/test files together.
